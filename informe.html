1. Resumen

JCHO Finanzas es una aplicación web (PWA) de finanzas personales que permite gestionar ingresos, gastos, ahorros, presupuestos y pagos recurrentes. Los datos se almacenan en la nube mediante Firebase Realtime Database y se sincronizan entre dispositivos. El login se realiza con Google.

2. Estructura del proyecto

  • index.html — Estructura de la interfaz web
  • styles.css — Estilos y diseño responsivo
  • app.js — Lógica de negocio y sincronización
  • manifest.json — Configuración PWA
  • logo.svg — Logo oficial

3. Funcionalidades

  • Registro de transacciones (ingresos/gastos) con categorías, cuenta y recurrencia
  • Filtros por mes, búsqueda y ordenamiento
  • Gráfico de dona por categoría y barras mensuales
  • Presupuesto mensual con barra de progreso
  • Ahorro mensual con historial
  • Recordatorios de pagos con notificaciones locales
  • Exportación CSV y PDF
  • Compartir resumen por WhatsApp
  • Modo claro/oscuro
  • Cambio de moneda (S/, $, €)

4. Arquitectura y sincronización

Los datos se guardan en Firebase Realtime Database bajo la ruta usuarios/{uid}. El login con Google (Firebase Auth) provee el ID de usuario. Las reglas de seguridad permiten lectura y escritura solo al usuario autenticado propietario de sus datos.

5. Seguridad

  • Login obligatorio con Google para sincronización
  • Reglas de Firebase que restringen acceso por usuario
  • Datos almacenados con cifrado en tránsito (HTTPS)

6. Despliegue

La aplicación se aloja en GitHub Pages: https://jchodigital-cell.github.io/jcho-finanzas/

7. Conclusión

El sistema ofrece una experiencia profesional de finanzas personales, segura, multiplataforma y con respaldo en la nube.
